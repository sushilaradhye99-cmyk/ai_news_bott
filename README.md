# 🤖 AI News Trading Bot

An intelligent Python automation project that fetches financial news, analyzes sentiment using AI, generates trading signals, and sends Telegram alerts automatically.

---

# 🚀 Features

✅ Real-Time News Fetching  
✅ AI Sentiment Analysis  
✅ Trading Signal Generator  
✅ Telegram Notifications  
✅ CSV Log Storage  
✅ Fully Automated  
✅ Python-Based Automation

---

# 🧠 Technologies Used

- Python 3.11
- Pandas
- Transformers (Hugging Face)
- Torch
- Telegram Bot API
